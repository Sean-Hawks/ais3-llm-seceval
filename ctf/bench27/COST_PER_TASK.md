# Bench27 每題成本明細（27 題 × 6 模型 = 162 格，每格為 5 個 epoch 的平均）

資料源 `bench27_cost.json`（803 有效樣本）。欄位說明：

- **input / output / 總 tok**：該樣本所有 model 呼叫的 token 加總，取 epoch 平均
- **訊息**：assistant 訊息數（＝ agent 實際走了幾步）；**out/訊息**：單次生成長度
- **working**：agent 實際工作秒數；**total**：牆鐘（含 gateway 排隊/退避）；**排隊稅** ＝ (total−working)/total
- **解出**：scorer 判 C 的 epoch 數 / 有效 epoch 數；**終止**：撞到的預算上限
